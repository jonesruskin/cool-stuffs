# Claude — Motion Reel ’26

A 15-second motion-design showreel in which **every frame and every note comes from code**.
It has no keyframes, stock footage or samples. The only external assets are three open-source typefaces.

▶ **[`claude-motion-reel.mp4`](claude-motion-reel.mp4)**: 1920×1080, 60 fps, H.264 + AAC, 15.000 s

## The idea

The reel is a résumé, so each scene shows one skill. Picture and sound share a single grid:
**128 BPM × 8 bars = 32 beats = exactly 15 seconds.** Every cut, bounce and particle burst
lands on a beat that `music.py` also scores.

| Beats | Scene | What it shows off | What you hear |
|---|---|---|---|
| 0–4 | **01 Ignition** | A clay dot springs to life inside construction guides and a live annotation, then squashes and shoots out into a seam | Heartbeat plucks A–C–E–G, a riser |
| 4–8 | **02 Emotion** | The seam splits the screen and becomes a baseline, and "motion" rises from behind it. An italic *e* runs the classic bouncing-ball exercise (motion path, onion skins, squash and stretch) to spell **emotion** | A chord stab, then one pitched "boing" per bounce |
| 8–16 | **03 Specimens** | A bento grid fills one tile per beat: easing, superformula morph, particles, 3D torus, type on a path, metaballs, ripple grid, loops | An ascending arpeggio, one note per tile, then a snare roll |
| 16–24 | **04 Particles** | The camera dives into tile 3. 4,200 particles go galaxy → **"Claude"** → explosion → 3D blob → ring → shockwave | The drop: supersaws, rolling bass, sidechain pump |
| 24–28 | **05 Craft** | "Every **frame.** / *curve.* / `note.` / pixel." with a different typographic treatment and accent on each beat, above the **actual waveform of this soundtrack** | A stab on each word |
| 28–32 | **06 Signature** | Everything collapses into the dot. The dot reveals the name and lands as its full stop | A sub boom, a lydian chord, a bell as the dot lands |

Craft details: true motion blur (up to 40 sub-frames averaged over a 180° shutter), fixed-point
camera zooms, a HUD with SMPTE timecode and a beat counter, film grain and a vignette.

## Files

```
reel/
  index.html      page + @font-face; open it (served over http) for a live, audio-synced preview
  reel.js         the whole film: render(ctx, t) is a pure function of time
  music.py        the whole soundtrack: additive/supersaw synths, drums, reverb, sidechain, mastering
  render.cjs      headless-Chromium frame renderer (4 workers) + ffmpeg mux
  assets/         music.wav + waveform.js (generated by music.py)
  fonts/          Instrument Serif, Inter Tight, JetBrains Mono (SIL OFL)
```

## Rebuild

```bash
pip install numpy scipy imageio-ffmpeg        # imageio-ffmpeg provides a static ffmpeg with libx264
npm i -g playwright                            # Chromium must be installed for Playwright
cd reel
python3 music.py                               # -> assets/music.wav, assets/waveform.js
FFMPEG=$(python3 -c "import imageio_ffmpeg as f; print(f.get_ffmpeg_exe())") \
  node render.cjs                              # -> build/claude-motion-reel.mp4  (~8 min on 4 cores)
node render.cjs --stills 2.84,8.8,14.5         # single frames at given seconds -> build/stills/
FRAMES=675-787 node render.cjs                 # re-render a frame range, keep the rest, re-mux
```

Live preview: `npx serve reel`, open it and press play. The preview draws one sample per frame,
so there is no motion blur.
